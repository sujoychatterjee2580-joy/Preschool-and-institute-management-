# 🎒 KiddieSync AI - প্রিস্কুল ও টিউশন সেন্টার ম্যানেজার SaaS

> **কমপ্লিট অল-ইন-ওয়ান এআই এসএএস প্রোডাক্ট (Preschool & Tuition Center Operating System)**
> হাজিরা (Attendance), স্মার্ট ফি রিকভারি (1-Click Fee Reminders & UPI), ২৪/৭ WhatsApp এআই অ্যাডমিশন চ্যাটবট, ডেইলি কিড ডায়েরি ও ড্রপআউট প্রেডিকশন।

---

## 🚀 কেন সেন্টার ওনাররা প্রতি মাসে এই সফটওয়্যারটির জন্য পেমেন্ট করবে? (৫টি অ্যাডভান্সড এআই ফিচার)

### ১. এআই স্মার্ট ফি রিকভারি ও এস্কেলেশন অটো-পাইলট (Fee Recovery Engine)
* **আসল সমস্যা:** প্রিস্কুল ও কোচিং সেন্টারগুলো প্রতি মাসে ১৫-২৫% ফি সঠিক সময়ে আদায় করতে পারে না। ওনার বা রিসেপশনিস্টদের জন্য অভিভাবকদের বারবার ফোন করা লজ্জাজনক ও বিরক্তিকর।
* **সমাধান:** ৩-টায়ার বন্ধুত্বপূর্ণ WhatsApp রিমাইন্ডার সিকোয়েন্স:
  - **লেভেল ১ (ডিউ ডেটের ৩ দিন আগে):** আন্তরিক শুভেচ্ছা সহ ভদ্র রিমাইন্ডার ও ১-ক্লিক UPI পেমেন্ট ডিপ-লিংক।
  - **লেভেল ২ (ডিউ ডেটের দিন):** তাৎক্ষণিক পেমেন্ট রিমাইন্ডার ও কিউআর কোড।
  - **লেভেল ৩ (ওভারডিউ):** ফরমাল এস্কেলেশন নোটিশ।
  - পেমেন্ট সম্পন্ন হওয়া মাত্রই স্বয়ংক্রিয়ভাবে ডিজিটালি স্ট্যাম্পড ইনভয়েস ও রিসিট WhatsApp-এ চলে যায়।

### ২. ২৪/৭ WhatsApp এআই অ্যাডমিশন কাউন্সেলর ও লিড কোয়ালিফায়ার (Admission Bot)
* **আসল সমস্যা:** ৬০%+ ভর্তি সংক্রান্ত ইনকোয়ারি আসে সন্ধ্যা বা ছুটির দিনে (অফিস আওয়ারের পর)। স্টাফরা উত্তর দিতে দিতে অভিভাবক অন্য স্কুলে ভর্তি করিয়ে দেয়।
* **সমাধান:** স্মার্ট এআই কাউন্সেলর বাংলা, ইংরেজি ও হিংলিশে অভিভাবকের প্রশ্নের রিয়েল-টাইম উত্তর দেয়, বাচ্চার বয়স অনুযায়ী ব্যাচ সিলেক্ট করে এবং স্বয়ংক্রিয়ভাবে স্কুল ভিজিট/ফ্রি ডেমো ক্লাস ক্যালেন্ডারে বুক করে ডিরেক্টরকে অ্যালার্ট পাঠায়।

### ৩. ডেইলি "কিড ডায়েরি" ও এআই প্যারেন্ট আপডেট (Daily Milestone Diary)
* **আসল সমস্যা:** ছোট বাচ্চাদের অভিভাবকরা সারাদিন টেনশনে থাকেন বাচ্চা খেলো কি না, ঘুমালো কি না। টিচারদের ১-২ ঘণ্টা সময় নষ্ট হয় ম্যানুয়ালি ডায়েরি লিখতে।
* **সমাধান:** টিচার শুধু ৪টি কুইক অপশন ট্যাপ করেন (Mood: Playful, Meal: 100%, Nap: 45 min, Activity: Finger painting) -> এআই তৎক্ষণাৎ একটি মিষ্টি, প্রফেশনাল ও স্নেহশীল ৩-লাইনের মেসেজ তৈরি করে অভিভাবকের WhatsApp-এ পাঠিয়ে দেয়। এতে অভিভাবকদের স্কুলের প্রতি বিশ্বস্ততা বহুগুণ বেড়ে যায়।

### ৪. কিয়স্ক কিউআর হাজিরা ও তাৎক্ষণিক সেফটি নোটিফিকেশন (Express Kiosk Attendance)
* **আসল সমস্যা:** ম্যানুয়াল খাতা কলমে হাজিরা নেওয়া ধীরগতির এবং অভিভাবকরা চিন্তায় থাকেন বাচ্চা ঠিক সময়ে পৌঁছালো কি না।
* **সমাধান:** রিসেপশনের ট্যাবলেট কিয়স্কে বাচ্চা পৌঁছানোর সাথে সাথে কার্ড স্ক্যান হয় (<১ সেকেন্ড) -> সাথে সাথে মায়ের ফোনে নোটিফিকেশন যায়: *"Kabir has arrived safely at Little Stars Academy at 08:58 AM"*। আর সকাল ৯:৩০-এর মধ্যে অনুপস্থিত থাকলে স্বয়ংক্রিয়ভাবে অসুস্থতা/ছুটির খোঁজ নিয়ে মেসেজ যায়।

### ৫. এআই স্টুডেন্ট ড্রপআউট প্রেডিকশন ও ফিন্যান্সিয়াল ইন্টেলিজেন্স (Churn Predictor)
* **আসল সমস্যা:** কোন বাচ্চা কোচিং বা প্রিস্কুল ছেড়ে দেওয়ার প্রস্তুতি নিচ্ছে তা সেন্টার ওনার বুঝতে পারেন বাচ্চাটি আসা বন্ধ করার ২-৩ সপ্তাহ পর।
* **সমাধান:** এআই উপস্থিতি কমে যাওয়া, ফি আটকে থাকা এবং অভিভাবকদের প্রতিক্রিয়ার প্যাটার্ন দেখে আগেই ফ্ল্যাগ করে দেয়: *"Aarav Chakraborty - ৭৮% Churn Risk"*। সাথে ১-ক্লিকে "We miss you" রিটেনশন মেসেজ ও ডিরেক্টর কলের গাইডলাইন প্রস্তুত থাকে।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Frontend & Backend:** Next.js 14 (App Router), React 18, TypeScript
- **Styling & UI:** Tailwind CSS, Lucide React Icons
- **Database & ORM:** SQLite (Zero configuration local setup) + Prisma ORM (প্রোডাকশনে PostgreSQL / Supabase-এ ১-ক্লিকে শিফট করা যায়)
- **WhatsApp Integration:** Meta WhatsApp Cloud API Ready + Built-in Local Audit Simulator
- **Payment Processing:** UPI Direct Deep Link / QR Code generator + Razorpay/Stripe Schema Ready
- **Multi-tenancy:** প্রতিটি স্কুলের আলাদা ডেটা আইসোলেশন ও সাবস্ক্রিপশন ট্র্যাকিং

## ⚡ কীভাবে চালাবেন (Quick Start)

### ১. ডিপেন্ডেন্সি ইনস্টল ও ডাটাবেস রেডি
প্রজেক্টটি ইতিমধ্যেই সম্পূর্ণ কনফিগার ও সিড করা আছে। নতুন করে শুরু করতে:
```bash
npm install
npx prisma db push
node prisma/seed.js
```

### ২. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:3000`
